# ♟️ Chess Clone

A real-time multiplayer chess game built with **Node.js, Express.js, Socket.io, and Chess.js**.

## 🚀 Features

* ♟️ Play chess with another player in real time
* ⚪ White and ⚫ Black player roles
* 👀 Spectator support
* ✅ Valid chess moves
* 🔄 Real-time board updates
* 🖱️ Drag and drop pieces
* 📱 Simple and clean interface

## 🛠️ Tech Stack

* **Node.js**
* **Express.js**
* **Socket.io**
* **Chess.js**
* **EJS**
